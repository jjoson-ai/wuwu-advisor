# Wuwu Advisor Brand Pack — Working Rules

## Brand name
Wuwu Advisor

## Core line
Clearer decisions. Better timing.

## Brand feel
- premium
- calm
- grounded
- modern
- useful
- reflective

Avoid:
- mystical cliché
- cringe spiritual language
- cheesy empowerment copy
- generic horoscope filler
- aggressive sales tone

## Product tone rules
- reflective, not deterministic
- precise, not mystical sludge
- sharper, not longer
- useful enough to act on
- calm enough to trust

## UX / copy rules
- free should feel useful, not chopped
- paid should feel meaningfully deeper, not merely unlocked
- CTA language should reinforce one premium tier where relevant
- structured outputs beat dense walls of text
- symbolic values should be explained in plain English
- label help and value descriptors should stay conceptually separate

## Monetization messaging rules
- launch with Free + Pro
- do not force credits into pre-launch messaging
- premium should be framed as fuller access, continuity, and deeper value
- later credit products should be framed around urgent decision support and deep dives

## Visual direction
- high negative space
- minimal but intentional hierarchy
- premium restraint over decorative spirituality
- motion should be subtle and confidence-building

## What the brand is not
- not a meme astrology app
- not a reader marketplace
- not therapy
- not generic AI advice with zodiac decoration
- not a one-shot report funnel

## Guidance for Codex and product work
Use this document to guide:
- CTA wording
- paywall copy
- locked-card copy
- landing page copy
- tooltip / descriptor tone
- premium-vs-free framing

Default rule:
if copy feels more dramatic than trustworthy, simplify it.
