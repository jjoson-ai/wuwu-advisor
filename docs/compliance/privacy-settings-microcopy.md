# Privacy Settings Microcopy

| Surface | Element | Copy | Notes |
|---|---|---|---|
| **Settings → Account** | Delete account button | “Delete my account” | Initiates deletion request.  Explain that deletion is manual and may take up to 30 days.  Mention that some billing records will be retained to satisfy legal obligations. |
| **Settings → Account** | Export data button | “Download my data” | Starts export of your prompts, birth profile and usage history.  Inform users they will receive a link via email. |
| **Settings → Privacy** | Birth profile toggle | “Include my birth details in readings” | Allows user to opt in/out of using their birth date/time/location.  Clarify that disabling will limit the accuracy of the Birth Blueprint and Forecast features. |
| **Settings → Privacy** | Analytics toggle | “Allow anonymised usage analytics” | Toggle for optional analytics (if implemented in future).  Currently defaulted off since only essential first‑party instrumentation exists. |
| **Settings → Subscription** | Upgrade button (free tier) | “Unlock Pro insights” | Explains benefits of Pro and that payment will be processed by Stripe.  Includes small print: “Wuwu Advisor is for entertainment only – not professional advice.” |
| **Checkout** | Payment information text | “Payments are processed securely by Stripe.  We never store your full card details.” | Builds trust at checkout. |
| **Onboarding** | Consent checkbox for birth data | “I consent to Wuwu Advisor using my birth details to generate my horoscope.” | Must be unchecked by default.  Links to privacy policy. |
| **Ask feature** | Disclaimer at top of chat | “Responses are generated by AI for entertainment and reflection; they are not medical, legal or financial advice.” | Encourages users to use output responsibly. |
| **Error state / slow payment** | Payment delay message | “We’re verifying your payment.  Pro access should activate within a few minutes.  If it doesn’t, please contact support.” | Addresses webhook delay risk. |
