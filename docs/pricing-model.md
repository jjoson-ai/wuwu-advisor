# Wuwu Advisor Pricing Model and Unit Economics

## Purpose
Standing pricing reference for future product, growth, and investor threads.
Use this as the default commercial baseline unless explicitly superseded.

## Launch model vs target model
### Launch model
- Free + Pro

### Target model
- Free + subscription + credits

### US-first rule
Optimize pricing, packaging, and web checkout for US users, then sell globally.

## Working price stack
- **Free** — $0 — habit layer, acquisition, daily return, upsell discovery
- **Plus** — $9.99/mo or $79.99/yr — lower-friction subscription anchor
- **Pro** — $19.99/mo or $149.99/yr — full premium tier, higher ARPPU anchor
- **Credits** — $4.99 / 5, $9.99 / 12, $19.99 / 30 — urgent, high-compute, high-intent usage
- **Deep dives** — standalone premium sessions/reports — to be tested post-launch

## What users should pay for
- urgency and decision clarity
- timing precision
- deeper personalized synthesis
- cumulative value over time, not generic daily text

## Unit-economics assumptions
- 30% installs -> MAU
- 4.5% installs -> paid
- paid mix: 75% Plus / 25% Pro
- 40% web / 60% mobile paid mix
- average credit attach: $2 gross per paid user per month

## Margin reality
- web users are more profitable than mobile users because of lower platform tax
- mobile is stronger for habit and push retention
- web should be favored for checkout, annual plans, and larger upsells
- total compute margin depends more on model routing and token discipline than astrology API vendor cost
- evaluate stack decisions on combined astrology + LLM COGS, not astrology vendor cost alone

## Critical profit levers
1. paid conversion
2. net ARPPU
3. paid retention
4. credit / upsell attach rate
5. web share
6. compute discipline

## Creditization rules
- first credit targets: premium Ask, timing reads, relationship/career deep dives
- do not creditize habit surfaces first
- add credits only after launch instrumentation shows under-monetized urgent demand

## Compounding value rule
Every premium session should create:
1. a user-facing artifact
2. a structured memory delta that can inform future Today / Forecast / Ask outputs

## Standing interpretation
Launch with Free + Pro, but treat that as Phase 1.
The long-term model is Free + subscription + credits, with upsells designed to improve future outputs rather than ending as isolated one-off artifacts.
